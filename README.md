# Урбанизация: окно в город

Учебная визуальная новелла по географии. 20 учебных сцен, главное меню и титры; музыка и саунд-дизайн Владислава Макаровского.

## Опубликовать на GitHub Pages

1. Распакуй RAR на компьютере. Загружать в репозиторий нужно содержимое архива, а не сам RAR.
2. Создай на GitHub публичный репозиторий, например `urbanization-game`.
3. Выбери `Add file → Upload files` (в пустом репозитории — ссылку `uploading an existing file`). Загрузи `index.html`, папки `assets` и `licenses`, файлы `.nojekyll`, `README.md` и `ASSET_SOURCES.md`. Файл `index.html` должен лежать в корне, без дополнительной папки вокруг сайта. Затем нажми `Commit changes`.
4. Открой `Settings → Pages`. В `Build and deployment` выбери `Source: Deploy from a branch`, ветку `main`, папку `/(root)`, затем `Save`.
5. Дождись завершения сборки Pages. В этом же разделе появится `Visit site`. Обычный адрес: `https://USERNAME.github.io/urbanization-game/`, где USERNAME — твой логин.

Сборка Node.js, установка зависимостей, GitHub Actions вручную и сервер для этого сайта не нужны.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Звук и управление

Нажми `♪ Включить звук` в меню, чтобы послушать начальную музыку. Браузер разрешает звук после действия пользователя. Кнопка `Начать` тоже разблокирует звук.

Enter или пробел: читать дальше; второе нажатие ускоряет текущую анимацию, дальнейшие нажатия до её окончания не пропускают содержание. Цепочки окон появляются автоматически, затем пробел закрывает их курсором. Кнопка сворачивания ставит игру на паузу. В настройках раздельно регулируются музыка, эффекты и общая громкость.

Звуковые файлы должны оставаться в `assets/audio`. Пути относительные: сайт работает и в подпапке репозитория. Не подменяй этот `index.html` большой автономной версией для локального просмотра.

В пакете находятся только готовые файлы сайта. Большие оригинальные WAV саундтреков, рабочие тесты и приватные папки не нужны для публикации и сюда не включены.
